# Studoo · Descargas

**Studoo** es un estudio para hacer música y beats, en español: secuenciador de pasos, piano roll, playlist, mezclador con efectos, kits de batería, 808, sintetizadores y un apartado **Aprende** con 56 lecciones, retos, tests y juegos para entrenar el oído.

## 📥 Descargar

Ve a **[la última versión](https://github.com/Salamalicul/Studoo-descargas/releases/latest)** y elige tu archivo:

| Sistema | Archivo |
|---|---|
| **Windows** (recomendado) | `Studoo-vX.X.X-Instalador-Windows.exe` |
| Windows (sin instalar) | `Studoo-vX.X.X-Windows.zip` |
| **Linux** (Ubuntu, Mint, Debian) | `Studoo-vX.X.X-Linux.deb` |
| Linux (otras) | `Studoo-vX.X.X-Linux.tar.gz` → descomprime y ejecuta `instalar.sh` |
| **Android** | En Google Play (pronto) |

Studoo se actualiza solo: cuando haya una versión nueva, te avisará al abrirlo.
